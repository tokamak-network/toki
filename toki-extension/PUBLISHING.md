# 크롬 웹스토어 배포 가이드

## 비용 / 요약

- **개발자 등록비 = 평생 1회 $5** (구글 계정당). **연회비·갱신 없음.** 환불 불가.
- 1회 등록으로 그 계정에서 **최대 20개** 익스텐션 게시 가능. **배포/호스팅 무료**, 유지비 0.
- 설치하는 **사용자는 무료** (웹스토어 자체 결제는 종료 — 유료화하려면 별도 결제 시스템 필요).
- **$5도 아끼려면**: **Edge 애드온**·**Firefox(AMO)** 는 등록비 **무료**. MV3라 Edge엔 거의 그대로, Firefox는 매니페스트 약간 조정 필요.

## 절차

### 1. 패키징
```bash
cd toki-extension
npm run build      # build/chrome-mv3-prod
npm run package    # → build/chrome-mv3-prod.zip  (이 zip 업로드)
```

### 2. 개발자 등록
- **Chrome Web Store Developer Dashboard** (`chrome.google.com/webstore/devconsole`) 로그인 → **$5 1회 결제** → 이메일 본인 인증(무료).
- 공식 토카막 배포면 조직 계정/그룹 퍼블리셔 권장(소유권 이전 번거로움 방지).

### 3. 아이템 생성 + 리스팅
대시보드 → **New item** → zip 업로드 → 리스팅 작성. 필수:
- 상세 설명, 카테고리/언어
- **스크린샷** 최소 1장(1280×800 또는 640×400)
- **128×128 스토어 아이콘** (빌드에 이미 포함)
- **단일 목적(single purpose) 설명**, **권한별 사용 사유**, **개인정보 처리 공개**

### 4. 개인정보 / 권한 사유 (이 익스텐션 특화 — 필수)
- **개인정보처리방침 URL 필수**: 사용자의 **지갑 주소를 `chrome.storage`에 저장**하고 **RPC로 잔액을 조회**함 → user data 수집에 해당. 정책 URL 없으면 리젝.
  - 핵심 문구 예: "지갑 주소는 **로컬(chrome.storage.local)에만** 저장, 외부 서버 전송 없음. 잔액 조회는 **공개 RPC 노드**로만 수행, 개인정보 수집·판매 없음."
- **권한 사유**:
  - `scripting` — 메타마스크 감지/주소 읽기용 MAIN-world 브리지 주입
  - `alarms` + `notifications` — TON 도착 알림
  - `storage` — 진행상황/주소 로컬 저장
  - host_permissions — 가이드 도메인 안내 + 잔액 조회 RPC

## ⚠️ 제출 전 반드시 손볼 것 (현재 상태의 리젝 위험)

1. **이름/설명 불일치** — 현재 `Toki — TON Staking Assistant` / "Chat with Toki anywhere…"인데 실제 핵심은 **온보딩 가이드**. `package.json`의 `displayName`/`description` + 리스팅을 실제 기능에 맞게 수정. (불일치 = 리젝)
2. **`<all_urls>` 채팅 오버레이가 최대 리스크** — `toki-overlay`가 모든 사이트에 뜨고 광범위 host 권한까지 있으면 ① **단일 목적 정책** 위반, ② **광범위 권한 정당화** 요구로 심사가 크게 까다로워짐.
   - **권장:** 첫 제출은 **온보딩 가이드만** (채팅 오버레이 제거/비활성), 권한도 `scripting/storage/alarms/notifications` + 가이드 5개 도메인으로 최소화 → "단일 목적: 지갑 생성·거래소 출금 온보딩 가이드". 승인 확률↑.
3. **크립토 + 거래소/메타마스크 도메인 주입** — 금융 사이트 콘텐츠 스크립트는 스크루티니가 셈. "출금 단계 안내 + 주소 복사만, 폼/입력 미조작"으로 사유 명확화.
4. **원격 코드 금지(MV3)** — 전부 번들됨, MAIN-world 브리지도 인라인 `func` → **문제 없음.**
5. **트레이드마크** — "MetaMask"·거래소 이름의 *설명적 사용*은 OK, 로고 무단 사용·사칭 금지.

## 제출 전 체크리스트

- [ ] 이름/설명을 "온보딩 가이드"로 수정 (`package.json` + manifest + 리스팅)
- [ ] 채팅 오버레이(`<all_urls>`) 제거 또는 가이드 도메인 한정 → 권한 최소화
- [ ] 개인정보처리방침 페이지 호스팅 (URL 확보)
- [ ] 스크린샷 1~5장 + 128 아이콘 준비
- [ ] `npm run package` → zip
- [ ] (선택) **비공개(Unlisted)** 또는 **Trusted testers**로 먼저 올려 내부 테스트 후 Public 전환

## 배포 옵션

- **Public** — 검색·공개.
- **Unlisted** — 링크로만 설치(검색 안 됨). 베타/내부 배포에 적합. 같은 심사를 거침.
- **Trusted testers** — 지정 계정만 설치(폐쇄 테스트).
